BUILD INSTRUCTIONS
==================

The algorithm is Python with two C++ extension modules.  Both extensions must be compiled
before the algorithm is run; without them the entry point still returns a feasible solution,
but a much worse one, because every hot loop lives in them.

FILES
-----
    myalgorithm.py    entry point.  algorithm(prob_info, timelimit) -> operations dict
    bayrepack.py      the exact bay-repacking operator (pure Python; calls cranepack)
    ogc_fast.cpp      construction engine (contact beam, rollouts, geometry)
    cranepack.cpp     maximum-weight set packing over space-time columns

REQUIREMENTS
------------
    Python           3.10 or newer (developed and measured on 3.12)
    C++ compiler     g++ with C++17 and OpenMP  (g++ 11 or newer)
    pybind11         pip install pybind11

    Python packages, all installed with pip:
        pybind11        required, build-time
        numpy           required
        shapely         required
        pyclipper       required
        threadpoolctl   optional; pins BLAS-style pools to one thread inside workers
        ortools         optional; enables the CP-SAT bay-reassignment operator.  The
                        algorithm detects its absence and runs the other five operators.

BUILD
-----
Run both commands in the directory holding the source files.  The resulting .so files must
sit beside myalgorithm.py, which imports them by name.

    g++ -O3 -shared -std=c++17 -fPIC -fopenmp $(python3 -m pybind11 --includes) \
        ogc_fast.cpp  -o ogc_fast$(python3-config --extension-suffix)

    g++ -O3 -shared -std=c++17 -fPIC -fopenmp $(python3 -m pybind11 --includes) \
        cranepack.cpp -o cranepack$(python3-config --extension-suffix)

Each takes roughly 30-60 seconds.  -w may be added to silence warnings; no warning in either
file affects correctness.

If the evaluation environment lacks OpenMP, drop -fopenmp from both commands.  The code
compiles and runs correctly without it -- the omp pragmas become no-ops -- and only loses the
parallel speedup inside the beam.

RUN
---
    import myalgorithm
    operations = myalgorithm.algorithm(prob_info, timelimit)

prob_info is the problem dictionary as provided; timelimit is in seconds.  The function
always returns a feasible solution and never raises: it establishes a cheap feasible schedule
first and only replaces it with something that scores better under the official feasibility
check.

The algorithm uses multiple processes, defaulting to min(8, cpu_count).  Set the environment
variable WORKERS to override; WORKERS=1 makes it single-process.

NOTES ON THE ENVIRONMENT
------------------------
No file is read or written at run time and no network access is used.  Nothing is cached
between calls except in-process memoisation, so repeated calls in one process are safe.

The algorithm honours the time limit it is given.  It reserves the last min(0.2*T, 40 s) for a
final improvement pass, so it returns slightly before the limit rather than at it.

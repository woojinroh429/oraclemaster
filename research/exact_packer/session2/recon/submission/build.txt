BUILD INSTRUCTIONS
==================

The two .so files in this zip are ALREADY COMPILED for the evaluation environment and no build
step is required to run the algorithm.  They were built on Ubuntu 24.04 LTS with Python 3.12,
matching the stated evaluation server, because the rules state that server-side compilation is
not performed.  The .cpp sources are included so the binaries can be inspected and rebuilt.

CONTENTS
--------
    myalgorithm.py    entry point.  algorithm(prob_info, timelimit) -> solution dict
    bayrepack.py      the exact bay-repacking operator (pure Python; calls cranepack)
    ogc_fast.cpython-312-x86_64-linux-gnu.so     construction engine, compiled
    cranepack.cpython-312-x86_64-linux-gnu.so    set-packing solver, compiled
    ogc_fast.cpp      source for the above
    cranepack.cpp     source for the above
    utils.py          unmodified copy of the provided module

REBUILDING (only if the binaries need to be regenerated)
-------------------------------------------------------
Requires g++ with C++17 and OpenMP, and pybind11 (pip install pybind11).  Run in the directory
holding the sources; the .so files must end up beside myalgorithm.py, which imports them by name.

    g++ -O3 -shared -std=c++17 -fPIC -fopenmp $(python3 -m pybind11 --includes) \
        ogc_fast.cpp  -o ogc_fast$(python3-config --extension-suffix)

    g++ -O3 -shared -std=c++17 -fPIC -fopenmp $(python3 -m pybind11 --includes) \
        cranepack.cpp -o cranepack$(python3-config --extension-suffix)

Each takes roughly 30-60 seconds.  Without OpenMP, drop -fopenmp: the pragmas become no-ops and
the code stays correct, losing only the parallel speedup inside the beam.

RUNTIME DEPENDENCIES
--------------------
Required, and all present in the provided conda environment:

    python 3.12, numpy, shapely

Optional.  Each is imported inside a try/except and its absence only disables one thing:

    ortools         enables the CP-SAT bay-reassignment operator; without it the other five
                    operators run and the algorithm is unaffected otherwise
    pyclipper       an alternative geometry path; shapely covers the same work without it
    threadpoolctl   pins BLAS-style thread pools to one thread inside worker processes

Nothing else is imported.  No file is read or written at run time, no network access is used,
and no path outside the execution folder is touched.

BEHAVIOUR THE EVALUATOR MAY WANT TO RELY ON
-------------------------------------------
algorithm() always returns a feasible solution and does not raise.  It establishes a cheap
feasible schedule first and only ever replaces it with a candidate that passes the provided
check_feasibility(), so a failure in any later stage degrades the result rather than the run.

It honours the time limit it is given and reserves the final min(0.2*T, 40 s) for an improvement
pass, so it returns slightly before the limit rather than at it.

It uses multiple processes, defaulting to min(8, cpu_count).  The evaluation server allows four
cores, and the default therefore resolves to four there.  Set the environment variable WORKERS to
override; WORKERS=1 makes it single-process.

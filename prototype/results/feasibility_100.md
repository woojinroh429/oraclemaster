# 100블록 feasibility 돌파 — greedy 시드(①) + top-k NMS(⑦)

## 결과 (prob_1, 전체 100블록)

| 구성 | 정수해 | 정확검증 | obj (Z1,Z2,Z3) |
|------|--------|----------|----------------|
| best-1 pricing (이전) | **INFEASIBLE** | - | - |
| top-k NMS ⑦ 만 | **INFEASIBLE** | - | (풀 6배로 두꺼워졌으나 호환 조합 없음) |
| **greedy① + top-k⑦** | **OPTIMAL** | **위반 0 → FEASIBLE** | Z1=32, Z2=483, Z3=754, obj=1.09e6 |

**100블록이 처음으로 실행가능해졌다.** greedy 시드가 0.3초에 100블록 무충돌 1벌을
만들어(Z1=32) 정수해 INFEASIBLE을 원천 차단, top-k NMS가 대안 열을 공급.

## 무엇이 무엇을 했나

- **⑦ top-k + NMS**: 라운드당 열 생성 99→728개(약 7배). 풀은 두꺼워졌으나, **그것만으론
  100블록 호환 배치가 풀에 존재한다는 보장이 없어 여전히 INFEASIBLE**이었다.
- **① greedy 시드**: EDD 순 + 비트마스크 fit + shadow 통짜 예약으로 **무충돌 1벌 보장**.
  이 1벌이 정수 모델에 들어가 있으므로 정수해는 최소한 greedy 해(Z1=32)를 항상 선택 가능
  → **INFEASIBLE 불가능**. 나머지는 CG/top-k 열로 개선.

## 아직 1499가 아닌 이유 (정직한 격차)

obj=1.09e6 ≫ 1499. 원인은 **Z1=32(지연)**:
- w1=29091 이라 지연 32 → 목적 93만. 대부분이 여기서 나온다.
- 슬랙 분석상 Z1=0은 원리적으로 가능한데, (a) greedy가 보수적(shadow 통짜 예약)이라 공간을
  낭비해 지연 유발, (b) ROUNDS=1 이라 열 풀에 Z1=0 조합이 아직 없음, (c) Z2/Z3 유도 부재.

## 1499로 가는 남은 일 (측정이 가리키는 순서)

1. **지연 제거(Z1→0)**: 열생성 라운드를 더 돌려 조기 EN·조밀 배치 열을 확보.
   → **여기서 pricing이 병목(순수 Python, 라운드당 수십초)** = Numba(측정 9x) 투입 지점.
2. **⑥ Z2/Z3 유도**: 마스터 LP 목적에 부하균형(Gmax-Gmin) + 선호손실 항을 넣어 균형/선호
   방향으로 열 생성.
3. **덜 보수적 greedy/래스터(θ↑)** + 최종 정확검증: 공간 낭비 축소로 지연 여지 제거.
4. **LP 안정화**: 100블록에서 셀 18만개 퇴화로 status-4 재발 → 제약 집계/Gurobi.

즉 이번 단계 목표(**100블록 feasibility**)는 달성. 1499(품질)는 위 4개, 특히 ①Numba로
라운드를 감당해 Z1을 0으로 떨어뜨리는 게 핵심.

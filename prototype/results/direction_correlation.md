# 배치방향 이득의 상관분석 — 밀도와 뒤집힌 U (실측 15 인스턴스)

## 데이터: Z1>0 인스턴스 15개 × 4방향(bigleft/bigright/bigtop/coreperi) 실측
승자: bigleft=21,27,30,35,38,39,40 / coreperi=23,26,32,33,36,37 / bigright=25 / bigtop=31.
(prob_36은 bigleft/right/top 전부 degenerate INFEAS, coreperi만 feasible -> coreperi 견고성도 제공)

## 결과 1: 단일 특징의 선형 상관 = 전부 약함 (예측 불가)
Pearson |r| ≤ 0.35. 최강: acv -0.35, bigfrac -0.33, n -0.27 (coreperi 이득 기준).
=> 어느 방향이 이길지는 단일특징으로 예측 불가 = 혼돈적 기하 상호작용 => best-of 정당.
(약한 방향성: 블록크기 균일(acv↓)·큰블록비중 낮음(bigfrac↓)일수록 coreperi 유리.)

## 결과 2: 밀도와 비선형(뒤집힌 U) — best-of 이득의 핵심 예측자 ★
| 밀도(_demand_ratio) | 개수 | 평균 best-of 이득 | 최대 |
|---|---|---|---|
| 저 <0.85 | 2 | 0.0% | 0% |
| **중 0.85~1.15** | 8 | **7.6%** | **18.7%** |
| 고 >1.15 | 4 | 1.2% | 4.9% |

이득 = 밀도의 뒤집힌 U. 중밀도에서 폭발(23:-18.7%,33:-17.4%,32:-13.3%).
선형 r(dens)=-0.24가 약했던 이유 = 관계가 비선형.

## 메커니즘
저밀도: 여유 넘침 -> 다 일찍 진입 -> Z1 작음 -> 방향 무의미.
중밀도: 빡빡하나 미포화 -> slack 존재 -> "연속유지 vs 조각화"를 방향이 결정 -> 레버리지 최대.
고밀도: 포화 -> slack 없음 -> 방향 무력 -> bigleft 근최적.

## 실전 규칙
best-of 방향탐색을 **중밀도(0.85<dens<1.15)에만** 적용 -> 평균7.6% 최대18.7% 이득.
저/고밀도는 bigleft 단독 충분. 밀도는 solving 없이 즉시계산 -> 게이팅 공짜.
2차: coreperi는 crane-degenerate 회피(prob_36 유일 feasible)로 견고성도 제공.

# 프로토타입 — 비트마스크 공간충돌그래프 + CP-SAT (정확 수리계획)

문서 `../model/bitmask_3d_approach.md` 의 아이디어를 실제로 구현·검증한 코드다.
"휴리스틱 없이 수리계획으로" 목표에 맞춰, 완전(complete) 솔버 CP-SAT로 **최적해**를 구하고
shapely 원본 다각형으로 **정확 feasibility 검증**까지 한다.

## 파이프라인 (solve_setpack.py)

1. **보수적 래스터화 → 비트마스크**: 각 (블록,배향,베이)를 딱 1회 shapely로 래스터화해
   레이어별 점유 마스크 `occ[L]`(int) 와 크레인 수직그림자 `shadow[L]=OR_{lev<=L} occ[lev]`
   를 만든다. 위치 이동은 shapely 재호출 없이 **비트 시프트** `mask << (dy*W+dx)` (핵심 가속).
2. **비트논리 충돌그래프**: 두 공간배치의 충돌을 비트 AND로 판정
   - 같은레벨 충돌: `occ_a[L] & occ_b[L] != 0`
   - 크레인 간섭: `shadow_a[L] & occ_b[L] != 0` (양방향)
   - **시간창 프루닝**: 가능한 [EN,EX) 구간이 절대 못 겹치는 블록쌍은 스킵.
3. **CP-SAT 모델**: 각 블록은 정확히 한 공간배치 선택(`sum s=1`), 시간은 정수변수
   `EN_i, EX_i=EN_i+P_i`, 지연 `T_i>=EX_i-D_i`. 공간충돌하는 두 배치가 모두 선택되면
   두 블록의 시간구간을 분리(disjoint) 강제. 목적 `w1*Z1 + w2*Z2 + w3*Z3`.
4. **정확 검증**: 해를 원본 다각형으로 컨테인먼트/같은레벨충돌/크레인/시간 재검사 후
   목적값 재계산. 제출형식 solution_out.json 출력.

## 실행

```
pip install numpy shapely ortools
python solve_setpack.py <instance.json> [n_sub] [sx] [sy] [maxwait] [timelimit]
# 예) python solve_setpack.py prob_1.json 9 5 5 3 60
```

## 검증된 결과 (prob_1, results/)

| 규모 | 그리드 | 배치수 | 충돌쌍 | 상태 | 시간 | 정확검증 | 목적(Z1,Z2,Z3) |
|------|--------|--------|--------|------|------|----------|----------------|
| 6블록 | SX=SY=4 | 2,882 | 139,187 | **OPTIMAL** | 7.0s | **위반 0 → FEASIBLE** | Z1=0, Z2=416.6, Z3=0 |
| 9블록 | SX=SY=5 | 3,086 | 203,750 | **OPTIMAL** | 13.2s | **위반 0 → FEASIBLE** | Z1=0, Z2=332.2, Z3=0 |

- 두 경우 모두 최적성 증명 + 원본 다각형 기준 실행가능. 블록들이 배향·위치를 바꿔가며
  같은 베이에 나란히 배치되어(예: 9블록에서 blk0=o1, blk6=o7) 실제 2D 패킹이 일어남.
- Z1=Z3=0: 이 블록들은 시간 여유가 있고 선호 베이에 다 들어가, 비용은 부하불균형 Z2뿐.

## 열생성으로 벽 돌파 (solve_colgen.py)

완전열거의 O(배치²) 충돌쌍 폭증을 **셀 제약 + pricing**으로 우회한다. 마스터 LP(GLOP)에서
배정 Σp=1·셀용량 Σp≤1 의 쌍대값을 뽑아, 블록별 감축비용 최소 열을 비트마스크로 탐색해
추가한다. LP 최적 후 생성열로 정수 set-partitioning(CP-SAT)을 풀고 정확검증한다.

| 블록수 | 생성열 | 셀제약 | 정수해 | 정확검증 | 목적값 |
|--------|--------|--------|--------|----------|--------|
| 6  | 52  | 20.8k | OPTIMAL 0.1s | 위반 0 | 2916.4 (완전열거와 동일) |
| 12 | 115 | 40.5k | OPTIMAL 0.4s | 위반 0 | 2026.2 |
| 20 | 205 | 66.7k | OPTIMAL 0.6s | 위반 0 | 19437.6 |
| 30 | 313 | 91.4k | OPTIMAL 0.9s | 위반 0 | 1917.8 |

완전열거가 터진 12블록이 열생성에선 1초 미만. 상세: `results/colgen_results.md`.

## 래스터 보수성 knob θ (품질 vs 안전)

`rasterize_mask(..., theta)`: θ=0=조금이라도 닿으면 점유(보수적/안전), θ↑=발자국 축소.
20블록 실험: θ=0 발자국 45.9셀·위반0, θ=0.25 발자국 36.4·위반0, **θ=0.5 발자국 31.3·위반 11
(INFEASIBLE)**. → 적당한 θ는 조밀배치 여지↑이나, 과하면 원본 다각형이 겹쳐 서버 탈락.
"덜 보수적"은 반드시 **최종 정확검증+수리**를 동반해야 함.

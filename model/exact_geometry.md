# 정확한 기하 제약 — 블록간 비겹침 & 크레인 제약 (NFP 기반)

v1(mathematical_model.md)의 AABB 근사는 블록을 외접 사각형으로 부풀려 품질을 떨어뜨린다
(오목·회전 형상일수록 손해 → 덜 들어감 → 지연 Z1 증가). 이 문서는 그 두 공간제약을
**근사 없이 정확히** 수식으로 정의한다. 핵심 도구는 No-Fit-Polygon(NFP)이다.

> 표기: ASCII. 아래첨자는 밑줄. 벡터 d = (dx, dy). 다각형 내부는 int(.).

---

## 0. 기하 원본 정의 (문제 재기술)

블록 i, 배향 o, 레이어 l의 다각형(기준점 상대좌표 고정)을 `Q_{i,o,l}` 라 하자.
기준점을 (x_i, y_i)에 놓으면 실제 배치 다각형은

```
P_{i,l}^{o,x,y} = Q_{i,o,l}  (+)  (x_i, y_i)      # 전체 평행이동
```

두 다각형이 **겹친다** := 내부 교집합이 비어있지 않다. 즉 비겹침(collision-free)은

```
int(P_{i1,l1}) ∩ int(P_{i2,l2}) = 공집합          # 변 공유(접촉)는 허용
```

문제의 C(...) 함수는 겹치면 1, 아니면 0. 우리는 이 "int 교집합 = 공집합"을
MIP 선형제약으로 정확히 옮긴다.

---

## 1. No-Fit-Polygon(NFP) — 비겹침의 정확한 특성화

고정 배향쌍 (o1, o2)와 레이어쌍 (l1, l2)에 대해 NFP를 다음으로 정의:

```
NFP(o1,l1 ; o2,l2)
  := { d : int(Q_{i1,o1,l1}) ∩ int( Q_{i2,o2,l2} (+) d ) != 공집합 }
```

즉 블록 i1의 기준점 대비 블록 i2를 d 만큼 옮겼을 때 두 레이어 내부가 겹치는
평행이동 d의 집합. 그러면 **정확한 비겹침 조건**은:

```
비겹침(l1, l2)  <=>  d_{i1,i2} = (x_i2 - x_i1,  y_i2 - y_i1)  가  int(NFP) 밖.
```

증명 아이디어: 두 다각형은 상대 평행이동 d에만 의존하며, 정의상 d ∈ int(NFP)가 곧
내부 겹침. 따라서 "겹치지 않음"은 d가 NFP 내부에 없음과 동치. 접촉(경계)은 허용되므로
"열린 내부의 밖"을 쓴다 → 변 공유 허용과 정확히 일치.

## 2. NFP의 선형(볼록분해) 표현

레이어 다각형은 **오목**할 수 있으므로, 두 단계를 거친다.

### 2.1 볼록분해
각 레이어 다각형을 볼록 조각들의 합집합으로 분해(삼각분할 등):

```
Q_{i1,o1,l1} = ∪_a  Qc_{a}        (볼록 조각 a)
Q_{i2,o2,l2} = ∪_b  Qc_{b}        (볼록 조각 b)
```

두 오목 다각형이 겹친다  <=>  어떤 볼록조각쌍 (a,b)가 겹친다.
따라서 **비겹침  <=>  모든 (a,b) 조각쌍이 비겹침.**

### 2.2 볼록조각쌍의 NFP는 볼록다각형
볼록 Qc_a, 볼록 Qc_b의 NFP는 볼록다각형이며(민코프스키 차 -Qc_a (+) Qc_b),
그 변(facet) e = 1..E(a,b) 마다 바깥향 법선 (A_e, B_e)와 상수 C_e가 있어

```
int(NFP_ab) = { d :  A_e*dx + B_e*dy < C_e   for all e }.
```

따라서 **d 가 이 볼록 NFP 밖(접촉 허용)**  <=>  적어도 한 변에서 바깥쪽:

```
∃ e :  A_e * dx  +  B_e * dy  >=  C_e.        # 분리평면(disjunction)
```

이 A_e, B_e, C_e 는 (o1,l1,o2,l2, 조각 a,b)마다 **오프라인 사전계산 상수**다.

### 2.3 정확한 비겹침 제약 (분리평면 disjunction, big-M)
조각쌍마다 이진변수 `g_{ab,e}` 도입. "모든 조각쌍 AND, 각 조각쌍 안에서 변 OR":

```
(G1)  sum_e  g_{i1,i2,ab,e}  >= 1                         for all pieces (a,b)
(G2)  A_e*(x_i2 - x_i1) + B_e*(y_i2 - y_i1)  >=  C_e
                                         - Mg*(1 - g_{i1,i2,ab,e})   for all a,b,e
```
- (G1): 각 볼록조각쌍은 최소 한 분리평면으로 떨어져야 함.
- (G2): 선택된 평면(g=1)에서 실제로 바깥쪽 부등식이 성립. Mg는 충분히 큰 상수
  (좌표 범위로 계산: Mg >= max|A_e|*Wmax + max|B_e|*Hmax + max|C_e|).

이것이 **AABB를 대체하는 정확한 블록간 비겹침**이다.

## 3. 배향(orientation)이 결정변수일 때의 활성화

배향 o1,o2 는 변수(v_io)이므로 NFP도 배향쌍마다 다르다. 배향쌍별 상수를 미리 만들고
해당 배향이 선택됐을 때만 (G1)-(G2)를 활성화:

```
(G3)  sum_e g_{i1,i2,ab,e}(o1,o2)  >=  v_{i1,o1} + v_{i2,o2} + del_{i1,i2} - 2
                                                for all o1,o2, pieces (a,b)
```
- `del_{i1,i2}` (v1 (C11c)): 같은 베이 & 시간중첩이면 1. 세 이진이 모두 1일 때만
  우변이 1이 되어 분리 강제. 아니면 우변<=0 → 비활성.
- (G2)의 A_e,B_e,C_e 도 (o1,o2) 인덱스를 달고, g 도 (o1,o2)로 분리해 둔다.

> 요약: 같은 베이·같은 기간·선택된 배향쌍에 대해서만, 각 볼록조각쌍이 한 분리평면으로
> 떨어지도록 강제. 근사 전혀 없음.

## 4. 레이어 충돌회피 제약 (동일 레벨, 모든 공존일)

문제 정의: 같은 날 같은 베이의 두 블록은 **같은 레벨 레이어끼리**(l1=l2=l) 비겹침.
따라서 §2.3의 정확 비겹침을, 레이어쌍 (l, l), l = 1..min(K_i1, K_i2) 에 대해,
del_{i1,i2}=1 (같은 베이 & 시간중첩) 조건으로 부과:

```
(LC)  §2.3의 (G1)-(G3)을  (l1,l2) = (l,l),  l = 1..min(K_i1,K_i2)  에 적용.
```

## 5. 크레인 제약 (교차 레벨, 반입/반출 순간)

문제 정의: 블록 i1을 넣거나(ENTRY) 빼는(EXIT) 순간, 그 순간 베이에 있는 다른 블록 i2에
대해, **i1의 레이어 l1 은 i2의 같거나 더 높은 레이어 l2 (l1 <= l2) 와 비겹침**이어야
크레인이 수직으로 통과한다.

### 5.1 크레인-클리어 술어
"i1이 크레인 대상, i2가 그 순간의 거주 블록"일 때:

```
CraneClear(i1 over i2)
  :=  모든 l1 = 1..K_i1,  모든 l2 = l1..K_i2 :   비겹침(l1, l2).
```
비겹침(l1,l2)는 §2.3을 레이어쌍 (l1,l2)로 쓴 것(교차 레벨이므로 l1<l2 조각쌍 NFP도 필요).

### 5.2 어느 순간, 누가 거주하는가 (활성 지시자)
문제의 거주집합 N(t,j) = { i : EN_i <= t < EX_i, 베이 j }. i1의 조작 순간은 두 개:
반입일 t=EN_i1, 반출 직전일 t=EX_i1 - 1. 각 순서관계를 이진 지시자로 정의(정수 시간변수 + big-M):

```
# i2 가 i1 반입 순간에 이미 거주  (EN_i2 <= EN_i1 < EX_i2, 같은 베이)
(K1a)  EN_i1 >= EN_i2 - Mt*(1 - en_{i1,i2})
(K1b)  EN_i1 <= EX_i2 - 1 + Mt*(1 - en_{i1,i2})
(K1c)  en_{i1,i2} <= sig_{i1,i2}                 # 같은 베이일 때만

# i2 가 i1 반출 순간(마지막 거주일 EX_i1-1)에 아직 거주
(K2a)  EX_i1 - 1 >= EN_i2 - Mt*(1 - ex_{i1,i2})
(K2b)  EX_i1 - 1 <= EX_i2 - 1 + Mt*(1 - ex_{i1,i2})
(K2c)  ex_{i1,i2} <= sig_{i1,i2}
```
(en, ex 는 "필요조건" 방향만 있으면 충분: 실제 거주 시 지시자를 1로 강제하려면
역방향 부등식도 추가하거나, 아래 (K3)에서 max로 처리. 안전하게 양방향으로 정의.)

### 5.3 크레인 제약 (활성 시 §2.3 부과)
i1이 크레인되는 순간 i2가 거주하면 CraneClear(i1 over i2) 강제:

```
(K3)  crane_{i1,i2}  >=  en_{i1,i2}         # 반입 순간 거주
      crane_{i1,i2}  >=  ex_{i1,i2}         # 반출 순간 거주

(K4)  crane_{i1,i2} = 1 이면,  모든 l1=1..K_i1, l2=l1..K_i2 에 대해
      §2.3의 분리평면 disjunction을 부과:
        sum_e g^{crane}_{i1,i2,l1,l2,ab,e}(o1,o2) >=
              v_{i1,o1} + v_{i2,o2} + crane_{i1,i2} - 2      for all o1,o2, a,b
      A_e*(x_i2-x_i1)+B_e*(y_i2-y_i1) >= C_e - Mg*(1 - g^{crane}_{...})
```
- **방향성**: (i1 over i2)와 (i2 over i1)은 서로 다른 순서쌍이다. i2가 나중에 반입/먼저
  반출되면 crane_{i2,i1}이 켜지고 레이어쌍 (l2' <= l1')로 반대 방향 제약이 걸린다.
  두 순서쌍을 모두 생성하면 문제의 비대칭 크레인 정의를 정확히 커버.
- l1=l2 조각쌍은 §4(LC)와 중복되지만 무해(같은 분리평면 강제).

## 6. AABB 대비 정확 모형의 트레이드오프

| 항목 | AABB (v1) | NFP 정확 (본 문서) |
|------|-----------|--------------------|
| 배치 품질 | 부풀린 사각형 → 덜 들어감 → 지연↑ | 실제 형상 → 조밀 배치 → 지연↓ |
| 크레인 제약 | 단일사각형 비겹침에 흡수(느슨) | 교차레벨까지 정확 표현 |
| 이진변수 수 | 쌍당 4개(방향) | 쌍·배향·레이어·조각·변 마다 → 폭증 |
| 전처리 | AABB만 계산 | 배향쌍·레이어쌍·조각쌍마다 NFP 사전계산 |
| 풀이 난이도 | 쉬움(1차 탐색용) | 어려움(정확·고품질) |

**실전 권장**: 크레인/레이어 정확식은 **평가 직전 검증 단계**나 **소수 충돌 쌍**에만
켜고(대부분 쌍은 시간창·베이 프루닝으로 제거), 배치 탐색은 휴리스틱+정확 NFP 국소보정으로
가는 하이브리드가 계산량과 품질을 모두 잡는 현실적 경로다.

### 사전계산 요약
- 각 (블록 i, 배향 o, 레이어 l) 다각형 → 볼록분해(조각 목록).
- 각 (배향쌍 o1,o2)·(레이어쌍 l1,l2)·(조각쌍 a,b) → 민코프스키 차로 NFP 볼록다각형 →
  변별 (A_e, B_e, C_e) 목록. 이 상수표만 있으면 (G1)-(K4)는 전부 선형.
